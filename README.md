# DroneVision

DroneVision — програма для перегляду відео з камери та телеметрії дрона.

## Завантаження

Завантажте інсталятор зі сторінки [останнього релізу](https://github.com/Pasichnyk100/DroneVision-Releases/releases/latest).

У розділі **Assets** оберіть файл інсталятора `DroneVision-...-Setup.exe`. Файл `latest.json` використовується програмою для перевірки оновлень — вручну запускати його не потрібно.

## Встановлення

1. Завантажте інсталятор зі сторінки релізу.
2. Запустіть файл `DroneVision-...-Setup.exe`.
3. Пройдіть кроки майстра встановлення.
4. Запустіть DroneVision через ярлик у меню «Пуск» або на робочому столі.

## Ліцензія

Під час першого запуску дотримуйтеся підказок у вікні ліцензування. Якщо у вас є ліцензійний файл, виберіть його в програмі.

## Перевірка оновлень

Відкрийте в програмі вікно **Інформація** та натисніть **Перевірити оновлення**. Якщо доступна новіша версія, програма покаже посилання на її інсталятор.

Для перевірки програма читає файл [`latest.json`](https://github.com/Pasichnyk100/DroneVision-Releases/releases/latest/download/latest.json), прикріплений до останнього GitHub-релізу.

## Важливо для випуску нової версії

До кожного релізу потрібно прикріпити:

- інсталятор DroneVision;
- файл `latest.json`.

У `latest.json` вкажіть номер версії та пряме посилання на інсталятор:

```json
{
  "version": "1.1.0",
  "installer_url": "https://github.com/Pasichnyk100/DroneVision-Releases/releases/download/v1.1.0/DroneVision-1.1.0-Setup.exe",
  "notes": "Опис змін у цій версії."
}
